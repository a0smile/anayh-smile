## 🧩 التحديات والحلول | Challenges & Solutions

<details>
<summary><b>⚙️ بناء تجربة متجاوبة</b></summary>

تمت مراعاة اختلاف أحجام الشاشات لضمان بقاء المحتوى والأزرار والتنقل
قابلة للاستخدام على الهواتف والأجهزة اللوحية وأجهزة الكمبيوتر.

</details>

<details>
<summary><b>🚀 الأداء وسرعة التحميل</b></summary>

تم تصميم الموقع بأسلوب يركز على تقليل العناصر غير الضرورية وتحسين
تجربة التحميل والتفاعل قدر الإمكان دون التضحية بالشكل البصري.

</details>

<details>
<summary><b>📱 تجربة الجوال</b></summary>

تم التركيز على تجربة مستخدم مناسبة للجوال باعتباره الوسيلة الأساسية
للوصول إلى خدمات الحجز والتواصل والموقع الجغرافي.

</details>

<details>
<summary><b>🛠️ إدارة المحتوى</b></summary>

تم تجهيز بنية تسمح بتحديث محتوى الموقع وإدارة البيانات دون الحاجة إلى
إعادة بناء جميع أجزاء الموقع يدوياً عند كل تعديل.

</details>

<details>
<summary><b>🔐 حماية وظائف الإدارة</b></summary>

تم فصل وظائف الإدارة عن واجهة الزوار وربط عمليات الحفظ الحساسة
بخادم API ومتغيرات بيئية بدلاً من وضع الأسرار داخل ملفات الواجهة.

</details>

<details>
<summary><b>🔄 الحفظ والنشر</b></summary>

تم تجهيز آلية للتعامل مع تحديثات المحتوى وحفظها في مستودع GitHub
عند توفر إعدادات الربط المطلوبة، مع الحفاظ على إمكانية تشغيل الموقع
حتى في حالة عدم تفعيل الحفظ الخارجي.

</details>
