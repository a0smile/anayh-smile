# موقع مجمع عناية الابتسامة الطبي — دليل النشر

هذا الملف جاهز للرفع إلى Cloudflare Pages. كلمة مرور المالك محفوظة الآن في متغير بيئي سري ولا توجد في أي ملف.

## خطوات النشر على Cloudflare Pages

1. ادخل إلى [dash.cloudflare.com](https://dash.cloudflare.com) → حسابك → **Workers & Pages**.
2. اضغط **Create** → **Pages** → **Upload assets** (أو Connect to Git إذا رفعت الكود على GitHub).
3. ارفع ملفات هذا المجلد كاملة (بما فيها مجلد `functions`).
4. بعد إنشاء المشروع، اذهب إلى صفحة المشروع → **Settings** → **Functions / Environment variables** (أو **Settings → Environment variables**).
5. اضغط **Add variable** وأدخل:

   | الاسم          | القيمة                        | النوع       |
   |---------------|-------------------------------|-------------|
   | `ADMIN_PASSWORD` | (كلمة المرور الجديدة التي تريدها) | **Secret** |

   > ⚠️ **Secret** = تُشفر ولا تظهر لأي شخص (هذا أهم إعداد). اختَر "Encrypt" إن ظهر الخيار.

6. غيّر كلمة المرور إلى شيء جديد **لا** تضع كلمة المرور القديمة التي كانت منشورة في كود قديم.
7. اضغط **Save** ثم **Redeploy** (إعادة النشر) حتى يسري المتغير.

## كلمة الدخول لوضع المالك
- زر الدخول: أيقونة **🔐** أسفل يسار الموقع.
- الكود = القيمة التي وضعتَها في `ADMIN_PASSWORD`.
- وضع المالك يتيح تعديل النصوص والأسعار والصور مباشرة في المتصفح، مع زر **تحميل content.json** للاحتفاظ بالتعديلات.

## ملاحظات أمان
- كلمة المرور ليست في أي ملف من ملفات الموقع — فقط في متغير Cloudflare.
- إذا استضفتَها على منصات أخرى غير Cloudflare (مثل GitHub Pages / Vercel static)، فلن يعمل التحقق الآمن، وسيظهر خطأ في الدخول. الحل متوفّر فقط مع Cloudflare Pages Functions.
- لا ترفع أي نسخة قديمة من `content.json` كان تحتوي على كلمة المرور.
